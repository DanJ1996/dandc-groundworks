# D&C Groundworks — Brand Kit

Locked-in brand foundation for the website redesign. Apply these consistently on every page.

## Colours

### Core
| Role | Name | Hex |
|------|------|-----|
| Primary | Navy | `#273E57` |
| Background | Beige | `#EDE7DF` |

### Supporting (derived from the core two)
| Role | Hex | Use |
|------|-----|-----|
| Navy dark | `#1B2C3E` | Footer, video/image overlays |
| Navy light | `#3E5975` | Hover states, subheadings, links |
| Beige dark | `#D8CFC2` | Card borders, dividers |
| Off-white | `#F7F4EF` | Alternating section backgrounds |
| Charcoal text | `#222831` | Body copy on light backgrounds |
| White | `#FFFFFF` | Text on navy / on video |

## Typography — Montserrat

| Element | Weight | Style |
|---------|--------|-------|
| H1 / Hero | Bold (700) | UPPERCASE, wide letter-spacing (~2px) |
| H2 / Section titles | SemiBold (600) | UPPERCASE, letter-spacing ~1px |
| H3 / Subheads | SemiBold (600) | Sentence case |
| Body | Regular (400) | Sentence case, line-height ~1.6 |
| Buttons / Labels | Medium (500) | UPPERCASE, letter-spacing ~1px |

## Usage rules
- Navy hero sections with faded drone footage behind; white uppercase Montserrat headings on top.
- Alternate content sections between Beige `#EDE7DF` and Off-white `#F7F4EF` so the page has rhythm.
- Buttons: navy fill `#273E57`, white text; hover to navy-light `#3E5975`.
- Body text on light backgrounds uses Charcoal `#222831`, never pure black.
- Video/image overlays: navy-dark `#1B2C3E` at ~55% opacity so text stays readable.
- Keep generous whitespace — professional, not cramped.
